# Activity class labels

The five ordered class labels used by
[`mwi_category()`](https://e4warning.github.io/mwi/reference/mwi_category.md),
from least to most activity.

## Usage

``` r
mwi_activity_levels()
```

## Value

A character vector of length five.

## Examples

``` r
mwi_activity_levels()
#> [1] "No activity"        "Low activity"       "Moderate activity" 
#> [4] "High activity"      "Very high activity"
```
