# Convert Kelvin to degrees Celsius

Convert Kelvin to degrees Celsius

## Usage

``` r
celsius_from_kelvin(kelvin)
```

## Arguments

- kelvin:

  Numeric vector of temperatures in Kelvin.

## Value

A numeric vector of temperatures in degrees Celsius.

## Examples

``` r
celsius_from_kelvin(c(273.15, 295.15))
#> [1]  0 22
```
